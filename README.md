## ✨ The Vision Behind Wishlight

I believe everyone deserves their own sky — a place where they can open up about their dreams, express their passions, and hold on to their wishes without hesitation.

That belief inspired **Wishlight**.

Wishlight is more than a digital wishlist. It is a personal night sky where wishes take the form of glowing lanterns, gently floating through the darkness. Every lantern represents something meaningful: a dream someone wants to achieve, a passion they want to pursue, or a wish they hope to fulfill.

Each wish can have a desired completion date — a small promise to yourself that gives your dreams a direction.

Above it all, the moon changes its dimensions to reflect its changing phases, inspired by the beauty of the real moon.

I wanted to create an experience that brings together technology, creativity, and emotion — turning an ordinary wishlist into something more personal, peaceful, and meaningful.

**Your wishes. Your timeline. Your own little sky.**

## 💖 Features

### 🏮 Floating Lantern Wishes
- Represent wishes as glowing lanterns in the night sky.
- Create a visually immersive alternative to a conventional wishlist.
- Let each lantern symbolize a personal dream, goal, or aspiration.

### 📅 Wish Completion Dates
- Associate a desired completion date with a wish.
- Give personal goals a target to work toward.
- Keep the intended timeline connected to the wish it belongs to.

### 🌙 Dynamic Moon Experience
- Feature a moon whose appearance or dimensions change to represent lunar phases.
- Add a natural, atmospheric element to the night-sky interface.

### 🌌 Immersive Night-Sky Design
- Use a night-sky-inspired visual environment.

- Make the interface feel personal rather than like a conventional productivity dashboard.

### 💭 A Personal Space for Dreams
- Bring wishes, passions, and aspirations together in one place.

## 🏗️ How It Works

At a conceptual level, Wishlight connects a person's wishes to a visual representation of their own sky.

1. **Create a wish** — express a dream, goal, or aspiration.
2. **Choose a desired date** — set the date you hope to fulfill it.
3. **Light up the sky** — represent the wish as a glowing lantern.
4. **Watch the sky evolve** — experience the changing moon and the collection of wishes in your personal night sky.

The exact storage, rendering, and synchronization behavior depends on the implementation in the application.

## 🚀 Getting Started

Run Wishlight locally to explore the application.

### Prerequisites

- Python 3
- Git
- A modern web browser

### 1. Clone the Repository

```bash
git clone <YOUR_REPOSITORY_URL>
cd <YOUR_PROJECT_FOLDER>
```

### 2. Create a Virtual Environment

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

On macOS or Linux:

```bash
source venv/bin/activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Application

If `app.py` is the application's entry point:

```bash
python app.py
```

### 5. Open Wishlight

Visit the local address shown in your terminal. For a typical Flask development server, this is:

```text
http://127.0.0.1:5000
```

*Follow the actual entry point and configuration in the repository if they differ from these examples.*
